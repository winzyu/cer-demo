Browser API helper

Some checks call the server directly as the logged-in user. Log in on the dashboard, open Developer Tools, go to Console, and paste this once. It prints the status and a short summary, never the token. Set BASE to the server behind the dashboard you are on: 5201 for Current, 5301 for Release.

const BASE = 'http://localhost:5201';   // 5301 on the Release dashboard
async function api(method, path, body) {
  if (!path.startsWith('/api/v1/')) throw new Error('Local API paths only');
  const token = localStorage.getItem('token');
  if (!token) throw new Error('Log in first');
  const r = await fetch(BASE + path, { method, headers: { Authorization: 'Bearer ' + token,
    'Content-Type': 'application/json' }, body: body ? JSON.stringify(body) : undefined });
  const text = await r.text();
  console.log(r.status, text.includes('\n') ? (text.trim().split('\n').length - 1) + ' data rows' : text.slice(0, 200));
}
const week = { startDate: new Date(Date.now() - 7 * 864e5).toISOString(), endDate: new Date().toISOString() };

If localStorage.getItem('token') comes back empty, look under Application, Local Storage for the key the dashboard uses and tell me its name; do not paste its value.
