## 2. What closed

**The source-of-truth veto.** Every range in the operator's "Water Quality Metrics — Source of
Truth" document is discarded. The veto is implemented in five places:

- **Prompt.** The `AUTHORITATIVE NORMAL RANGES` block is gone. The model may state a limit only from
  a tool result, and a document's range is never the pod's limit.
- **Tools** (under `SENSOR_TOOL`):
  - `get_pod_thresholds` returns validated registry thresholds; rejected values come back with a
    reason, never the number.
  - `get_turbidity_info` returns the voltage conversion, the operator's three bands, the off-scale
    flag, and the fact that 0 can mean a missing reading.
- **Report.** Every numeric baseline is the pod's registry threshold. `BASELINE_RANGES` and
  `DO_ABSOLUTE_THRESHOLDS` are deleted, and there is no fallback. A *blind-spot note* is printed when
  a configured limit sits at the probe's physical floor or ceiling and so can never be crossed.
  Two safeguards the code review added:
  - A pod with no usable threshold for any numeric metric reports **"Not assessed"**, not "Normal".
  - A failed registry lookup is reported as a lookup failure, not as missing configuration.
- **Corpus.** The document is removed entirely (user's choice: its ranges were woven through every
  chunk). Archived under `corpus-archive-2026-09-13`.
- **Fixtures.** The `precedence` class is rewritten as "document range ≠ pod limit" (3 fixtures). The
  rubric lines that cited the removed document are gone.

**Quote citations, in code and demonstrated.**

- **The marker.** Context excerpts are labelled `【n】`, and the model writes `【n†"quote"】`.
- **Checking.** `checkQuotes` verifies each quote. The chat UI renders a numbered superscript whose
  tooltip is the source name, and the quote never reaches the DOM.
- **Smoke capture** (gpt-oss-120b, gold context, $0.0075 across three runs):
  1. First run: the model closed every marker with `"}`, so the checker read zero.
  2. A closing-bracket rule fixed that (10/10 closers correct afterwards).
  3. A stricter quote rule got a quote into every citation, but 3 of 4 quotes were table cells under
     the 12-character minimum.

  That is enough to show the lever is connected. It is not a measurement.

**Turbidity.** Operator bands adopted (`f751932`), and the prompt's 0–25 NTU range deleted.

## 5. Findings opened this session

1. **Backend turbidity conversion** (`../clean-earth-rovers-server/src/utils/turbVoltToNTU.ts`)
   returns 0 for a missing voltage and for the firmware's offline sentinel, the same as for clear
   water. A run of zeros is not confirmed clear water. The fix belongs in the server repo.
2. **That file's header names the sensor as the KS0414 (Keyestudio)**, the qualitative-only model.
   Pods carrying the quantitative sensor need a sensor-model registry field before chat can treat
   their numbers differently.
3. **`src/report/events.ts` still encodes the removed document's signature-matrix patterns.** These are
   directions of movement, not ranges, so they are outside the veto. Their provenance is now a
   document that is not in the corpus.
4. **The configured device token sees 5 pods**, where the August census saw 15. Tokens are scoped to
   one organization.
5. **The model's first citation attempt was malformed in a way that read as zero.** This is the
   silent-failure class 2a warned about. Both the checker and the chip parser now have tests built on
   the exact strings the model produced.
